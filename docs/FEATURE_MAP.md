# Ruomu Card Platform: capability map

Verified from the local checkout on 2026-09-29. This is a scoped navigation aid, not a complete product audit or a replacement for [existing guidance](../README.md). Recheck implementation when using it; extend entries only as tasks confirm the relevant behavior. Do not treat roadmap ideas as implemented features.

| Capability | Entry / UI | API / orchestration | Implementation / data | Review boundary |
|---|---|---|---|---|
| User storefront and admin console | [apps/user/src/router](../apps/user/src/router), public `/`, admin `/admin/` | [apps/admin/src/router](../apps/admin/src/router) | [apps/api/internal/router/router.go](../apps/api/internal/router/router.go), [deploy/nginx/prod.conf](../deploy/nginx/prod.conf) | Keep api, user and admin independently built applications; serve the admin SPA under `/admin/` on the primary user domain; retire the legacy `rm.meta-api.vip:8443` entry point. | AI content translation | [AI translation settings and usage](09-AI内容翻译.md), [shared editor control](../apps/admin/src/components/admin/TranslateContent.vue) | `GET/PUT /admin/settings/translation`, `POST /admin/translations` | [Qwen-MT service](../apps/api/internal/service/translation_service.go), private `translation_config` setting | Admin saves automatically update Traditional Chinese/English from Chinese when enabled (including clearing targets for empty source); bounded private translation cache avoids repeated provider calls. Apply only after all calls succeed and form remains unchanged. Manual generation remains optional. Separate configuration/use RBAC; never expose stored key or cache through generic/public settings. Direct third-party business API calls are unchanged. |
| Build and deployment | [scripts/build.sh](../scripts/build.sh) | [scripts/deploy.sh](../scripts/deploy.sh) | [deploy](../deploy) | Preserve three-app builds and TLS/callback checks; never record real keys or certificates in notes. |

Retain separate Go API and user/admin frontends. Existing scripts pin pnpm for application work; Bun is only the note-check runtime.

Before adding a feature, inspect adjacent flows and the current source of truth; shared filters, data definitions and access rules must not diverge across entry points.

# AI 内容翻译（Qwen-MT）

## 配置与使用

1. 在后台「系统设置 → AI 翻译」填入接口 Base URL、翻译模型和 API Key，启用翻译并保持「保存时自动翻译（以中文为准）」开启。旧配置未设置此开关时默认开启。
2. 默认模型为 `qwen-mt-flash`；默认 Base URL 为北京地域兼容地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`。也可以使用百炼业务空间专属 Base URL 或转发 Qwen-MT `translation_options` 的 HTTPS 中转接口。密钥、地域及模型访问权限应匹配；不要在 Base URL 中包含 `/chat/completions`、密钥或查询参数。
3. 点击「测试已保存配置」，使用固定中文样例验证英文译文。测试同样产生供应商调用，使用已保存的设置。
4. 编辑内容时只需填写简体中文，直接点击页面原有保存按钮。系统自动检查并生成繁体中文、英文，然后保存。自动模式以中文为准，会覆盖已有译文（含人工译文）；中文为空则清空对应译文。
5. 相同中文、模型、接口地址和目标语言优先复用成功缓存；修改中文或模型后重新翻译。若需保留手工目标语版本，可关闭「保存时自动翻译」。下方手动按钮仅为可选预览/重新生成入口，绕过缓存并更新成功结果。

支持商品（含嵌套多语言字段）、商品分类、文章、文章分类、轮播图、会员等级、站点基本文案/介绍/法律页面、导航、首页公告、订单邮件模板、通知模板及管理端分销商站点配置。原有前台读取方式、内容存储和三端独立构建保持不变；普通网址、价格、ID、脚本及非多语言配置不参加翻译。现有语言为简中、繁中、英文，增加其他站点语言仍需扩展站点语言资源及服务端白名单。

## 权限与密钥

- `GET/PUT /api/v1/admin/settings/translation`：独立配置接口，GET 仅返回 `has_api_key`，不返回密钥。空密钥保留已保存值；关闭后勾选删除可清除密钥。
- `POST /api/v1/admin/translations`：提交 `{ "text": "中文", "target_locale": "en-US" }` 或 `zh-TW`，返回 `{ "text": "译文", "target_locale": "en-US" }`，不保存任何业务内容，成功结果写入私有翻译缓存。保存前调用增加 `use_cache: true`；普通手动调用不复用缓存。
- `system_admin` 可配置并翻译；`operations`、`integration` 可翻译但不能修改模型配置；只读、客服、财务角色默认不能调用。自定义角色需显式授予翻译调用权限及 `GET /admin/settings/translation` 配置检查权限。
- 通用 `/admin/settings` 对 `translation_config` 和 `translation_cache` 读写均拒绝，防止绕过独立权限或读出密钥。公开站点配置不包含模型设置。
- 密钥按项目现有 settings 存储方式保存在服务端数据库中，数据库备份应按含密钥资料保护。客户端只发送待译内容与目标语种，不接触已存密钥。

## 失败与格式处理

保存流程先读取最新翻译开关，再检查所有多语言字段。全部成功且当前表单未变化才回填并继续业务保存；配置读取失败、翻译失败、关闭编辑器或等待期间修改表单都会停止本次保存，保留原表单。重复点击保存不会启动第二轮任务。正常业务保存仍可能因字段校验或服务器错误失败，已回填译文留在表单以便重试。

成功缓存以 SHA256(接口地址、模型、源文、目标语言) 为键，不存源文或密钥；缓存内容为译文，作为私有 settings 数据保存。每个站点最多 256 条且序列化后不超过 2 MiB，超限淘汰最早生成的记录。淘汰后或多个 API 进程同时首次翻译可发生再次调用，不能作为严格计费去重。缓存命中仍检查翻译开关；手动重新生成跳过缓存。关闭整个翻译服务或自动模式、不具调用权限时，管理端沿用普通保存。

自动触发位于现有管理后台保存入口，不会扫描改写未打开的历史商品，也不改变第三方直接调用业务 API 的行为。

后端发送单条 user 消息及 `translation_options.source_lang/target_lang/domains`，不使用通用聊天 system 提示词。HTML 标签、URL、Markdown 链接目标、代码片段与常用模板变量以占位符保护，检查数量与顺序后恢复；模型丢失格式、生成新的受保护结构、空响应或截断结果均作为失败。Markdown 普通排版和翻译质量仍需检查。

每字段最多 12000 字符、请求最多 25 秒、响应最多 256 KiB，每 API 进程最多 4 个同时进行的翻译请求；不自动重试。更低的供应商输入限制仍适用，过长内容需拆分。HTTPS 地址限定默认端口，连接时拒绝私网 IP 与重定向。上游错误体和密钥不回传、不记录原始请求。

## 验证

`./scripts/build.sh` 执行后端全量测试和三端构建。管理端 build 同时执行 `node --test tests/translation.test.mjs`，覆盖手动补空/覆盖、自动更新所有译文、中文清空、开关关闭、嵌套语言对象、失败原子性、配置读取阶段竞态和关闭编辑器。服务端测试使用模拟上游验证 Qwen 协议、格式保护、异常、持久缓存命中/失效/淘汰以及密钥/权限边界。

真实模型效果与额度需要填入实际密钥后使用测试按钮验证；本次没有使用生产凭据调用或改动生产配置。

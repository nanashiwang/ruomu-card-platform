# Agent Note: 保存时自动翻译并以中文为准

Status: implemented

## Problem

用户希望填写中文后正常保存即可，不需要额外点击翻译按钮，并明确要求中文修改时自动更新全部已有译文。上一版显式生成流程不能满足此目标。

## Decision

复用现有 Qwen-MT 服务、字段遍历和各编辑页保存流程。启用翻译时默认开启 auto_on_save，保存前自动获取当前配置并为全部非空中文生成繁中/英文，覆盖已有译文。全部成功且表单未变化才回填并继续原有业务保存；失败、关闭编辑器或并发编辑停止保存。禁用翻译或无调用权限时保持原保存行为。

以接口地址、模型、源文和目标语言摘要缓存成功译文，存入独立私有 settings key；有限条数/字节上限，淘汰后按需重新生成。缓存命中避免重复供应商计费。手动重新生成绕过缓存并更新缓存。中文是自动模式的唯一来源，现有手写目标语也会被覆盖；需要保留人工版本可关闭自动模式。不引入数据库结构迁移、后台扫描或生产全量改写。

## Existing capabilities and note audit

检索命中 [Qwen 内容翻译](2026-11-04-qwen-content-translation.md)。它仍持有密钥、权限、模型协议与结构保护规则；本篇部分取代其手动触发/人工保存决定，双方互链。已检查所有现有翻译入口及对应保存函数、settings 旁路和发布约束。

## Alternatives considered

- 输入时防抖生成能更早预览，但输入过程会产生多次计费，用户尚未决定保存且容易覆盖新编辑；选择保存时自动检查。
- 每次保存直接重译实现最少，但无变化的保存重复消耗模型额度；增加有上限的共享翻译缓存。
- 后台扫描全部历史内容能免除逐页操作，但扩大计费与数据改写范围，需要持久任务、冲突处理和进度管理；本次聚焦用户正在保存的配置。

## Verification

`./scripts/build.sh` 通过全量 Go 测试、API 构建及 user/admin 类型检查和构建；前端 9 项回归通过，部署工具 40 项测试通过。服务端验证缓存持久复用、源文/语种/模型失效、手动绕过、失败不缓存、开关关闭拒绝缓存命中、条数及字节上限，以及通用设置拒绝访问缓存。前端验证自动覆盖已有译文、清空源文同步清空目标、关闭开关、配置/模型异常、读取配置期间编辑竞态和取消。

Playwright 在真实管理前端与模拟 API 上验证无翻译点击直接保存、更新已有英文、提交 use_cache、模型失败不写业务数据、关闭自动模式恢复普通保存。所有现有翻译页面及设置子页均接入同一保存前检查；输入中并发改动沿用原有整轮快照保护。

## Consequences

无需单独点击翻译，中文为单一来源；已有手写译文也会覆盖。首次保存大量字段需等待多次模型调用；关闭自动模式保留手工保存选择。每站点缓存上限为 256 条/2 MiB，以最早生成记录优先淘汰。缓存淘汰或多 API 进程竞争可引起额外调用，不能视为计费去重保证。真实 Qwen 密钥与生产部署仍不在此次验收范围。
